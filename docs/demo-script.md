# Demo Script

## Two-Minute Product Walkthrough

1. Open the local Inspector and invoke `open-studio`.
2. Show the GitHub OpenAPI operation catalog. Point out the supported GET operations and the visibly unsupported webhook POST operation.
3. Select or remove an operation and show the three-operation limit.
4. Edit a selected tool's name, description, input label/default, result limit, safety annotations, and view type.
5. Save locally and export the human-readable `app-config.json`. Explain that this prototype deliberately requires review and restart before runtime changes take effect.
6. Invoke `get_repository_overview` for `mcp-use/mcp-use` and show the repository summary card.
7. Invoke `list_repository_issues` and show the responsive issue table.
8. Invoke `list_top_contributors` and show the ranked contributor list.
9. Close with the product thesis: Manufact supplies the MCP build, inspection, deployment, and observability layer; this Studio explores the configuration layer above it.
