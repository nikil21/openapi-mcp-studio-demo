## Camera and Cursor Notes

- Use a 1440 x 900 browser window and record at 1080p when practical.
- Keep the cursor still during narration; move it only to identify an on-screen control.
- Use cuts between Studio, Chat, and deployment evidence. Do not show navigation or wait states longer than two seconds.
- If a live screen is slow, use the matching committed screenshot as a cutaway rather than retrying mid-recording.
